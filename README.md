# HUELLAS EN LA MADERA

Sitio web de presentación para una empresa de diseño y fabricación de muebles personalizados.

## Archivos
- `index.html`: contenido y estructura.
- `styles.css`: diseño visual y adaptación a móviles.
- `script.js`: menú y pequeñas interacciones.
- `assets/`: carpeta para fotografías propias.

## Antes de publicar
1. Sustituir las imágenes ilustrativas por fotografías reales autorizadas.
2. Incorporar el WhatsApp, teléfono, correo y ubicación oficiales del negocio.
3. Revisar textos, productos y datos comerciales con el cliente.
4. Probar el sitio en celular y computador.

Las imágenes externas actuales son únicamente ilustrativas y no deben presentarse como trabajos realizados por la empresa.

## Publicación
El proyecto puede publicarse posteriormente en GitHub Pages.
